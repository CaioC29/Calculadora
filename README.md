# Calculadora

### Ferramenta para realização de cálculos para plataformas Android e IOS


---

### Funcionalidades:

* Adição
* Subtração
* Multiplicação
* Divisão
* Raiz Quadrada

---

### 2. Objetivo do Sistema

Desenvolver uma aplicação mobile multiplataforma (Android e iOS) capaz de executar operações matemáticas básicas com interface amigável e resposta imediata ao usuário

---

### 3. Tecnologias Utilizadas

-   **React Native**
    
-   **TypeScript**
    
-   **Node.js**
    
-   **Expo (para desenvolvimento)**

---

### 4. Requisitos do Sistema

  #### 4.1 Requisitos Funcionais

 
RF01 – O sistema deve permitir inserir números através de botões numéricos

RF02 – O sistema deve permitir realizar operação de adição (+)

RF03 – O sistema deve permitir realizar operação de subtração (−)

RF04 – O sistema deve permitir realizar operação de multiplicação (×)

RF05 – O sistema deve permitir realizar operação de divisão (÷)

RF06 – O sistema deve calcular a raiz quadrada de um número

RF07 – O sistema deve exibir o resultado no visor

RF08 – O sistema deve permitir limpar os valores inseridos

<br>

#### 4.2 Requisitos Não Funcionais


RNF01 – O aplicativo deve responder às operações em tempo real

RNF02 – A interface deve ser simples e intuitiva

RNF03 – O aplicativo deve ser compatível com Android e iOS

---


### 5. Regras de Negócio

1.  A divisão por zero deve exibir mensagem de erro
    
2.  O resultado deve substituir o valor atual no visor
    
3.  Após uma operação concluída, o usuário pode iniciar uma nova operação automaticamente

---

### 6. Fluxo de Funcionamento

1.  Usuário digita um número
    
2.  Seleciona uma operação
    
3.  Digita o segundo número
    
4.  Pressiona “ = "
    
5.  O sistema calcula e exibe o resultado
    

**Para raiz quadrada:**

1.  Usuário digita um número
    
2.  Pressiona botão “ √ ”
    
3.  O sistema calcula e exibe o resultado


---

### 7. Possíveis Melhorias Futuras

-   Histórico de cálculos
    
-   Modo científico (potência, seno, cosseno, etc.)
    
-   Tema escuro
    
-   Suporte a porcentagem
    
-   Testes automatizados
    
    ---

### 8. Critérios de Aceitação

-   Todas as operações devem funcionar corretamente
    
-   A interface deve ser responsiva
    
-   O aplicativo não deve travar ao inserir valores inválidos
    
-   O cálculo da raiz quadrada deve apresentar resultado correto
